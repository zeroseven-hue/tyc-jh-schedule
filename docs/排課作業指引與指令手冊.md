## 壹、排課前觀念釐清：何時需要 API Key？何時完全免費？

很多組長會擔心「排課排太多次會不會把 API Key 額度用光？」。請放心，系統架構將兩件事完全分開：

| 工作項目 | 使用技術 | 是否需要 API Key？ | 費用與限制 |
| :--- | :--- | :--- | :--- |
| **全校24班自動排課運算** | Google OR-Tools CP-SAT (數學求解) | **完全不需要！** | 100% 免費、本地/Google Colab 執行、無限制排幾千次 |
| **排課衝突時草擬「委婉說帖信」** | LLM 大語言模型 (如 NVIDIA Build / Gemini) | **需要 (選配)** | 使用免費開發者額度即可，只有在「要 AI 寫信」時才調用 |
| **調代課通知 (寄發 Email)** | 學校 Google 帳號 (Gmail SMTP) | **不需要** | 免費，只需在學校主機/ Colab 設定應用程式密碼即可發信 |
| **調代課通知 (發送到 LINE 群組)** | LINE Notify 或 LINE Messaging API | **不需要付費 API Key** | LINE 官方提供免費權杖 (Token)，學校群組接收完全免費 |

> **總結**：您即使「完全沒有 API Key」，排課、調代課、發 Email、發 LINE 依然可以 100% 正常順利運作！API Key 只用來「請 AI 幫忙潤飾委婉的說話語氣」。

## 貳、標準排課流程（四大步驟）

### 步驟 1：準備設定資料 (Excel 範本)
* 檔案位置：`D:\antigravity\行政\01_國中智慧排課系統\templates\桃園國中24班_排課設定表.xlsx`
* 包含四個關鍵工作表：
  1. `教師名冊`：姓名、授課領域、導師/專任（自動核對桃園最新導師 10/12 節、專任 16/18 節）。
  2. `不排課時段`：教師進修日、公假時段、領域教學研究會共同時段。
  3. `週三本土語分組`：指定 701+702、703+704 等兩兩分組與外聘客語/原民語教師時段。
  4. `特教資源班抽離`：設定 2~3 班（如 701+702）國英數抽離綁定群組與資源班教師。

### 步驟 2：執行排課 (使用 Google Colab，免安裝環境)
1. 打開瀏覽器，進入 Google Colab (https://colab.research.google.com/)。
2. 上傳並開啟檔案：`D:\antigravity\行政\01_國中智慧排課系統\colab\桃園國中智慧排課引擎.ipynb`。
3. 將您填好的 `排課設定表.xlsx` 上傳至 Colab 左側檔案區。
4. 點選選單「**執行階段**」->「**全部執行**」（或快捷鍵 `Ctrl + F9`）。
5. 運算約 15~40 秒後，Colab 會自動打包並下載：
   * `全校24班課表_總表.xlsx`（包含各班課表、全校大表、教師個人課表）
   * `timetable_data.json`（供網頁匯入的資料檔）
   * `排課衝突與診斷報告.txt`（若有無法滿足的條件，列出明確說明）

### 步驟 3：在專屬網頁檢視與微調 (三種風格自由切換)
1. 在電腦上打開：`D:\antigravity\行政\01_國中智慧排課系統\web\index.html`。
2. 點擊「匯入課表檔案」，選取剛才產出的 `timetable_data.json`。
3. 您可以：
   * 下拉切換 701~908 班級課表、或各任課教師課表。
   * 右上角隨時切換「**日系可愛風** / **簡約黑白風** / **莫蘭迪優雅風**」。
   * 一鍵輸出成精美列印格式或 PDF。

## 肆、排課無法完全滿足時：AI 委婉說帖範例

當條件真的卡死（例如：週三下午本土語與特教抽離時間夾擊，導致某位專任老師不得不在不可排時段上一節課），可以使用 API Key 讓 AI 生成這類委婉得體的說明信：

> **主旨：【教務處教學組】115學年度第1學期課表初步排定說明與協調懇請**
> 
> 敬愛的林老師您好：
> 
> 首先非常感謝您長期對教務工作與學校孩子的辛勞付出！
> 
> 本學期全校課表在兼顧「特教資源班跨班抽離同調」以及「本土語文（閩、客、原）分組跑班師資時段」的多重法規限制下，排程空間極度嚴峻。
> 
> 我們深知您原先登記週四下午有個人進修/事務安排，但在反覆運算與多方嘗試調動超過 30 次後，週四第 6 節若未由您授課，將導致 701 與 702 兩班特教抽離時段全面中斷衝堂。
> 
> 萬不得已在此時段為您排入一節課，教學組深感抱歉！若該時段確實對您造成極大困擾，教務處隨時歡迎您前來討論，我們定當竭盡全力協助尋求其他同領域同仁對調之可能性。再次感謝您的包容與體諒！
> 
> 教務處教學組 敬上

## 伍、調代課與 LINE 群組 / Email 自動發信機制

開學後，老師請假調代課是每日日常。通知機制設定方式如下：

### 1. 寄送 Email (免付費 API Key)
* **做法**：使用 Python 內建的 `smtplib` 模組，透過學校的 Google Workspace（@ms.tyc.edu.tw 或一般 Gmail）的「應用程式密碼」發信。
* **特色**：系統一產生調代課單，自動將「代課通知單 PDF」寄至被指派代課老師的電子信箱。

### 2. LINE 群組發送通知 (免付費 API Key)
* **做法**：在 LINE 開發者後台申請一組免費的 **LINE Notify Token** 或 **LINE Messaging API 權杖**。
* **運作範例**：
  教學組長在系統登記：「王老師 10/15 (三) 第 3 節請公假，由 李老師 代課 803 數學」。
  按下送出，系統自動推播至學校教務群組或個人 LINE：
  ```text
  📢【教務處課務通知】調代課指派
  ─────────────────────
  請假教師：王大明 老師 (公假)
  代課教師：李美華 老師
  受代班級：803 班
  代課節次：10月15日(三) 第 3 節 (數學)
  代課地點：803 教室
  ─────────────────────
  代課鐘點費已列入本月結算清冊，感謝老師的協助！
  ```

## 陸、常見問題與求救指南 (FAQ)

* **Q1：如果跑排課跑出「無解 (Infeasible)」怎麼辦？**
  * 系統內建「部分排課 Relaxation」機制，它**絕不會直接當機**，而是會先排出 99% 的課表，並在診斷報告中明確寫出「哪兩位老師在哪一節互相衝突」，只要打開 Excel 將該限制放寬 1 節即可重新一鍵排通。
* **Q2：網頁可以在沒有網路的電腦上看嗎？**
  * 可以！`web\index.html` 是完全獨立的本地單一網頁，即使斷網也能正常顯示、切換三種風格與列印。
